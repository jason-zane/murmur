## Actual rendering finding and fix

The current Mac GUI was available. The earlier lock reading was stale; screen capture and existing Accessibility access both worked. The baseline preview rendered Today but crashed on opening Notes with AppKit's “more Update Constraints in Window passes than there are views” exception. Removing the geometry wrapper alone did not fix it and was reverted. Replacing the nested `HSplitView` with a fixed-width Notes list, separator and flexible detail pane eliminated the reproducible loop.

The list uses existing `DS.Layout.sidebarWidth`; no new literal size, colour or alternative design system was introduced. The containing window and detail remain responsive. The inner list divider is no longer draggable; this is the bounded tradeoff for a stable pane. The normal system navigation toggle is retained. The earlier outer `.toolbar(removing: .sidebarToggle)` modifier did not remove it in actual rendering, so that ineffective modifier was removed rather than continuing to claim the toggle was gone.
