# Workspace design

Quiet, modern and native remains the brand commitment. System typography, semantic surfaces and hairline separators establish hierarchy. Indigo means interaction; red means recording only. Native views use DesignSystem tokens and existing controls. Australian English and the product vocabulary in AGENTS.md apply throughout.

Four everyday destinations lead navigation. Related tools sit beneath their workspace, while app setup and preferences sit at the bottom. The active workspace determines toolbar actions. Today combines calendar activity with notes and offers an optional, dismissible setup invitation. Calendar and Mail explain missing connections at the point of use.

Connected apps is organised by task: calendars, Gmail and AI assistance. Each row explains the outcome and provides a clear next action. Account maintenance and technical configuration follow in disclosures. First-run guidance is short, can be skipped and can always be reopened. Never block local work on an optional cloud account.

Native sheets are reserved for guided setup and protected editing; ordinary navigation stays in the workspace. All sheets have a visible close action. Embedded web flows retain account isolation and never expose refresh credentials to page scripts.

## 30 September refinement

The default setup is a connected workspace: sign in to Concourse, then connect Google calendars and Gmail. Offline access is part of this experience; local-only notes/dictation remain a secondary path. Never require microphone/Accessibility permissions to browse Calendar or Mail.

Booking links and Dictation history are permanent peer destinations. Do not conditionally add/remove navigation rows. Calendar opens in Week at 08:00, with pinned day headings, opaque event blocks, a stable toolbar and compact status disclosure. Polling must preserve visible content and scroll position. Time-zone and offline details belong in the status popover or relevant settings.
